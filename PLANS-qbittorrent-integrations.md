Описание интеграции с qbittorrent.
==================================

Backend
-------

[x] Фильмы в Vault в категории "Буду смотреть" имеет привязку к раздаче, которая возникает, когда мы жмем кнопку Download в kinozal
[x] Все фильмы в Vault в категории "Буду смотреть" имеют статус привязки. Так можно сразу в интерфейсе видеть, какие фильмы связаны (link) с qbittorent, какие нет. 
[x] Каждый vault фильм (при наличии линка qbt) должен должен хранить сам torrent-файл на disaster-случаи. Если есть torrent, фильм можно восстановить (перекачать). Торрент файлы хранятся в специальной папке, монтируемой в docker (напр. mfp-torrents директория).
[x] Каждый vault фильм (при наличии линка qbt) должен хранить путь к файлу (или папке) в фильме Vault.
[x] Добавление фильма должно происходит не через горячую папку, как сейчас, а через API qbittorent.
[x] Привязанные фильмы имеют линк на страницу сайта торрента (если ее можно выцепить из torrent-файла)
[ ] "Живое" взаимодействие с front выполняется через websocket (например, обновление процента выполненного скачивания)
[x] Логин, пароль и url qbittorent хранятся в preferencies, для этого там нужно сделать отдельный раздел.
[x] id у раздачи - это infohash
[ ] К одному фильму может быть привязана несколько раздач. Но возникновение второй раздачи - это нештатная ситуация, и нужно продумать ее обработку (главное - сигнализацию пользователю). То есть если пользователь случайно скачал фильм повторно, это должно где-то сигнализироваться в интерфейсе. Но это нужно оставить на поздюю фазу выполнения.
[x] Персистентное логирование действий.
[ ] Можем ли мы сохранять торрент файлы с оригинальным названием, или переименовывать их соотв. фильму?
[ ] "Пишутся события torrent_deleted / torrent_delete_failed с payload: infohash, имя, флаги удаления, причина, ошибка." - куда они пишутся?

UI VAULT
---------

[x] В левом верхнем углу всех фильмов в категории "Буду смотреть" отображается "статус привязки". Используем https://lucide.dev/icons/link-2 и https://lucide.dev/icons/link-2-off
[x] Если фильм скачивается, отображаются проценты скачивания.  
[ ] При установке отметки "ПРОСМОТРЕНО" появляется модальное окно - предлагает удалить файл из qbittorrent (и торрент из mfp-torrents). Так же есть отдельная кнопка "Удалить раздачу"
[x] Фильтр, чтобы видеть все неприлинкованные фильмы.
[x] Отдельная возможность прилинковать фильм к раздаче qbittorent, если и раздача и фильм были созданы вручную.
[ ] Кнопка-линк для перехода в UI QBITORRENT к фильму (выполняется фильтр по id, чтобы в списке был только выбранный фильм)
[ ] Проценты обновляются polling’ом каждые 5 секунд - будем делать переход на websocket?

UI QBITORRENT
-------------

[x] Сначала просто таблица раздач
[ ] Затем фильтрация и сортировка (вторым этапом)
[ ] Возможность вручную добавить torrent файл через UI QBITORRENT интерфейс, при этом он автоматом добавляется в vault и устанавливается как "Буду смотреть"
[x] Кнопка-линк для перехода в Vault к фильму из раздачи

Конкретное описание
==================================

Backend
-------

[ ] Фильмы в Vault в категории "Буду смотреть" имеет привязку к раздаче, которая возникает, когда мы жмем кнопку Download в kinozal
[ ] Все фильмы в Vault в категории "Буду смотреть" имеют статус привязки. Так можно сразу в интерфейсе видеть, какие фильмы связаны с qbittorent, какие нет. 
[ ] Если есть привязка, мы должны хранить сам torrent-файл на disaster-случаи. Если есть torrent, фильм можно восстановить. Торрент файлы хранятся в специальной папке, монтируемой в docker.
[ ] Добавление фильма происходит не через горячую папку, а через API
[ ] Привязанные фильмы имеют линк на страницу торрента (ее можно выцепить из torrent-файла)

Реализация:

- есть готовая либа 
 
    uv add qbittorrent-api

Пример:

```python
from qbittorrentapi import Client
qbt_client = Client(host='http://localhost:8080', username='admin', password='your_password')
```

# Добавить торрент

```python
from qbittorrentapi import Client

qbt_client = Client(host='http://localhost:8080', username='admin', password='your_password')

# Добавить торрент
qbt_client.torrents_add(
    urls='magnet:?xt=urn:btih:...',
    category='movies',
    is_sequential_download=True
)

# Получить список активных скачек
downloading = qbt_client.torrents_info(status_filter='downloading')
```

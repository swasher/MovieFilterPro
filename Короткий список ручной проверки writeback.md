Короткий список ручной проверки writeback

[x] Watchlist+favorite+rating: на фильме с tmdb_id переключить «Буду смотреть» → фильм появился в TMDB watchlist; поставить избранное → TMDB favorite; поставить оценку 8 → TMDB rating (проверить в TMDB вкладке account/watchlist-favorites-rating).
[x] Рейтинг/статус удаляются: снять оценку и «Буду смотреть» → исчезло из TMDB.
[x] SKIP-лист: пометить «Не интересует» → фильм появился в TMDB-списке «Не интересует»; снять → исчез.
[x] Списки: создать список, добавить фильм → TMDB-лист создан и фильм в нём; убрать фильм → убран из TMDB; переименовать список → имя обновилось на TMDB.
[x] Удаление UserMovie: удалить фильм из фильмотеки → чистится watchlist/favorite/rating на TMDB.
- Хрупкие случаи async: быстро переключить статус туда-обратно 3 раза → на TMDB конечное состояние, в логе 1-2 записи, не 6.
- Retry: временно испортить токен → при toggle появилась запись в /tmdb-writeback очереди; вернуть токен → Retry из очереди проходит.
- Ручной Push: кнопка "Push to TMDB" на фильме возвращает тост и синхронизирует сразу.

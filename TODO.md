РЕДАКТИРОВАНИЕ СПИСКОВ
-----------------------

- Внизу левого сайдбара делаем кнопку Edit
- При нажатии Edit:
  - у каждого списка (кроме системных) появляется две маленьких иконочки - Карандашик и Корзина. 
  - Внизу появляется кнопочка Add (рядом)
  - "Edit" меняется на "Done"
- При нажатии на карандашик появляется модальное окно "Переименование": Текстовое поле с новым называнием, кнопки Save и Cancel.
- При нажатии на Корзину появляется модальное окно стиля warning: Кнопки Delete и Cancel
- При удалении списка удаляются лишь теги из фильмов, сами фильмы остаются.
